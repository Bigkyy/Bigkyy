# LiquidLeaf Reader (MVP Scaffold)

This repository now contains a deployable SwiftUI MVP scaffold for an Apple-platform reading app.

## What is implemented
- iOS app target (with Mac Catalyst enabled) generated by **XcodeGen**.
- Book import via Files picker: `.epub`, `.txt`, `.pdf`.
- Library list and reader screen.
- Reader theme switching (5 background presets).
- Hideable bottom tool panel (tap content to toggle).
- Basic page navigation controls (placeholder for skeuomorphic page-curl animation).
- Reading progress + recent history persistence.
- Localization for English + Simplified Chinese.

## Project structure
- `project.yml`: XcodeGen project definition.
- `LiquidLeafApp/Sources`: SwiftUI app code.
- `LiquidLeafApp/Resources`: localized resources (`en`, `zh-Hans`).

## Deploy to your iPhone / iPad / Mac (step-by-step)

### 1) Prerequisites
- macOS with latest Xcode installed.
- Apple ID signed into Xcode (for personal signing).
- Homebrew installed (recommended for XcodeGen):
  - `brew install xcodegen`

### 2) Generate Xcode project
From this repo root:

```bash
xcodegen generate
```

This creates `LiquidLeafReader.xcodeproj`.

### 3) Open and configure signing
1. Open `LiquidLeafReader.xcodeproj` in Xcode.
2. Select target **LiquidLeaf** → **Signing & Capabilities**.
3. Choose your Team.
4. If needed, change Bundle Identifier to something unique (e.g. `com.<yourname>.liquidleaf`).

### 4) Run on device
1. Connect iPhone/iPad with cable (or configured wireless debugging).
2. In Xcode toolbar, select your device.
3. Press **Run**.
4. If prompted on device, trust developer profile:
   - Settings → General → VPN & Device Management → trust your Apple ID cert.

### 5) Test core flow on device
1. Open app → **Library**.
2. Tap **Import Book** and choose an EPUB/TXT/PDF from Files.
3. Open the book.
4. Tap reader area to hide/show bottom toolbar.
5. Change theme via segmented control.
6. Navigate pages with Previous/Next to update progress.
7. Go to **Continue** tab and confirm reading progress + history.
